# 微信成员端

配套的微信小程序源码，提供身份关联、开荒报名、队伍成员、档期排行榜和个人信息。网站管理端承担成员及档期管理；旧入队审核和小程序管理接口已退役。

## 配置与发布

1. 先按根目录 README 安装后端，并为真实部署配置 HTTPS。
2. 在微信开发者工具导入此目录。将 `project.config.json` 中的 `touristappid` 换为自己的 AppID；私人开发者设置不要提交。
3. 将 `miniprogram/config.js` 的 `apiOrigin` 改为自己的 HTTPS 站点。默认 `https://clan.example.com` 只是占位域名。
4. 在后端平台设置中启用微信，配置与小程序一致的 AppID、AppSecret，以及所需订阅消息模板；秘密只存服务端。
5. 在微信后台配置实际请求、下载域名和头像、昵称所需的隐私保护说明。
6. 在自己的微信账号、真机和后端完成登录、关联及报名验收，再按微信平台流程上传和发布。

本仓库不包含可用 AppSecret、生产 AppID、二维码或已审核的小程序发行包。微信开发者工具和真机验证需要部署者自己的账号。

## 关联方式

同一部手机：在小程序「信息关联」获取关联码，复制网站地址到浏览器，使用 KOOK 登录已有战队账号并输入关联码，再回小程序核对后确认。

电脑：网站访问 `/app/wechat-link`，使用 KOOK 登录后生成二维码；通过小程序扫描并核对身份。

关联码和二维码有效期为 5 分钟。最终确认由用户完成；不会按昵称自动匹配或创建成员。网站已有社区身份、资格和 Steam 绑定必须有效。

## 开发验证

在仓库根目录使用项目指定的 Node.js 版本：

```sh
npm run test:mini
npm run verify --prefix wechat-miniprogram
```

小程序使用 `/api/v2/mini-program` 和微信换取的 Bearer 会话；网站关联接口使用现有 Cookie、Origin 和 CSRF 校验。测试覆盖身份关联、访客隔离、报名冲突、重试幂等及资料访问边界，外部微信/KOOK 证明由回环替身提供。测试通过不代表已完成真实平台登录、编译、审核或发布。
